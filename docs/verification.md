## 执行检查

```sh
pnpm install --frozen-lockfile
pnpm check
```

完整检查依次包含 typecheck、lint、全部测试、前端构建和 Worker dry-run。Windows 上 workerd 需要允许启动其本地子进程；环境拒绝执行不是业务测试失败，也不能伪报通过。

定向检查示例：

```sh
pnpm exec vitest run tests/html-hosting.test.ts tests/html-shares.test.ts tests/site-shares.test.ts
pnpm exec vitest run tests/resource-efficiency.test.ts
```

编辑器与 Markdown 渲染是延迟加载模块，构建体积提示需结合实际加载路径判断，不通过删减语言、预览或编辑能力来消除提示。

## 浏览器验收清单

以下为完整回归清单；本轮实际完成范围以上方发布检查为准：

1. 桌面、手机宽度和真实移动浏览器中检查侧栏/底部导航、长文件名、弹窗、键盘焦点、触摸操作和横向溢出。
2. 中英切换即时生效，英文长文案不挤出按钮；刷新保留偏好，切换页面/语言不清空上传队列；文件内容不被翻译。
3. 拖入多个HTML，检查目录、进度、完成后自动分享；模拟发布失败，重试只注册已有file_id；撤销后迟到重试不重新公开。
4. 单HTML直出原页面；文件夹网站在源站和反代加载CSS、模块、JSON、字体和相对子页；无iframe，外部资源按兼容规则拒绝。
5. 密码分享解锁、撤销、恢复、过期、下载开关、复制失败的手动回退。
6. 图床默认列表、全量画廊和大图，MD5链接、下载统计与撤销/恢复；Markdown图片上传和发布快照。
7. 登录、TOTP和恢复码操作由用户本人完成；语言切换不影响会话与分享权限。
8. 使用目标版本的 ShareX 和 RaiDrive/Windows 挂载验证真实上传、下载、重命名、锁定、删除及大文件限制。

接口返回了正确 CSP 不等于浏览器已实际执行所有脚本；协议测试通过不等于目标 WebDAV 客户端已实机挂载成功。浏览器工具受到访问限制时必须记录缺口，不能绕过限制或用旧截图替代本轮结果。
