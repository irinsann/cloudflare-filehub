开发验证环境为 Windows、Node.js 24、pnpm 11。业务测试运行在 Cloudflare workerd，使用隔离的本地 D1/R2，并应用仓库中的 SQL 迁移，不访问生产存储。测试数量和执行耗时以当前 `pnpm check` 输出为准。

## 本地执行

首次安装与本地数据迁移：

```sh
pnpm install --frozen-lockfile
pnpm db:local
```

完整发布前检查：

```sh
pnpm check
pnpm peers check
```

`pnpm check` 顺序执行 TypeScript 检查、ESLint、业务测试、前端生产构建和 Worker dry-run。它不会发布生产 Worker。需要定位问题时可单独运行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 或 `pnpm worker:check`。

CodeMirror 编辑器与 Markdown 渲染代码不在首屏加载；编辑器延迟块可能出现构建体积提示，应结合实际加载路径判断，不应通过移除语言或预览能力来消除提示。

## 浏览器检查

运行 `pnpm dev` 后打开 `http://127.0.0.1:8787`。使用本地样例数据完成以下检查，不在生产环境创建测试 Token 或修改私人文件：

- 桌面、平板和手机：文件列表/网格、搜索、排序、分页、长名称、空回收站；检查横向溢出和不必要滚动。
- 导航与对话框：底部导航、完整导航抽屉、键盘焦点、Esc、关闭后的焦点恢复、移动键盘与安全区域。
- 文件上传：空文件、普通文件、超过 16MiB 的分片文件、失败反馈与重试；完成后下载核对内容。
- 图床与 API：MD5 名称、Image-hosting 目录、重复图片复用、直链可读取、Token 创建/撤销及 ShareX 配置导入；列表打开不请求图片，点击预览后才加载，关闭后卸载；撤销后可恢复或确认彻底删除；引用和下载次数分别显示。
- Markdown：保存、冲突反馈、草稿恢复、桌面双栏、手机编辑/预览切换、公开快照与附件撤销。
- 登录与公开页面：密码/TOTP 表单、恢复入口、分享密码表单、文章目录和代码复制；切换亮色/暗色。
- HTML 分享：在分享地址直接显示原始 HTML，无外层站点或 iframe；检查内联交互、密码解锁后重载原地址、关闭下载与桌面/手机布局；确认页面不能读取本站 Cookie、本地存储或请求站点 API。

布局截图存放在 `docs/screenshots/`，覆盖文件页、编辑器、阅读页、分享页及登录页。截图与业务测试互为补充：现有自动化主要覆盖接口、安全和数据一致性，尚未建立持续运行的浏览器 E2E 套件。

## 生产发布检查

按 [部署指南](deployment.md) 确认资源绑定及配置；有待应用迁移时先迁移，再运行生产部署命令。前端重设计本身不需要重置账号、迁移用户文件或清空存储。

部署后验证实际域名与反代的登录页可加载、未登录管理 API 被拒绝、上传 API 仍需要 Bearer Token、公开文章/分享/直链遵守原有权限。登录脚本语法可单独检查：

```sh
node scripts/check-login-script.mjs https://233334.xyz/login
node scripts/check-login-script.mjs https://s.irin.im/login
```

脚本只验证登录页内联脚本的 JavaScript 语法；完整登录、真实客户端上传及账号套餐下的请求体/CPU 配额仍需各自验收。Cloudflare 配额、证书、反代连通性和生产运行状态以实际账号及部署结果为准。
