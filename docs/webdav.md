# WebDAV

WebDAV 与网页使用同一份文件和目录。通过客户端上传、移动或删除文件后，刷新网页即可看到变化。删除进入回收站，公开分享随删除关闭；WebDAV 不提供永久清空回收站的入口。

## 连接

在网页的 **设置 → WebDAV** 创建独立凭据。密码只显示一次，可以设置 30、90 或 365 天有效期，随时撤销。它与网页登录密码、验证器验证码和上传 API Token 不通用。

| 配置          | 值                        |
| ------------- | ------------------------- |
| 协议          | WebDAV，启用 HTTPS        |
| 全球 CDN 地址 | `https://233334.xyz/dav/` |
| 香港反代地址  | `https://s.irin.im/dav/`  |
| 用户名        | `rcloud`                  |
| 密码          | 设置中生成的 `rcd_…` 密码 |

在 RaiDrive 中新增 WebDAV 连接，填写其中一个地址及上述用户名、密码。两种地址访问同一数据，不需要重复上传。只有香港代理正确透传 WebDAV 请求时，反代地址才能正常使用。

目前已进行协议接口测试，尚未完成 RaiDrive 图形客户端的实际挂载验收。不同客户端的锁、属性和覆盖流程可能不同，请先用少量非重要文件验证上传、下载、重命名及删除。

独立凭据具有网盘文件读写权限，但不能登录管理后台、创建 Token 或发布分享。生产环境只接受 HTTPS；仅显式启用本地开发模式时允许本地 HTTP。不要把密码放入 URL、截图或公开配置。

## 文件大小与容量

- 单次 WebDAV `PUT` 上限为 **100,000,000 字节**，约 95.37MiB。客户端应发送准确的 `Content-Length`。
- 网页和现有上传脚本使用 16MiB 分片，不受此 WebDAV 单次请求上限约束。普通 WebDAV 客户端不会自动采用 RCloud 的分片协议。
- 单纯增加反代允许的请求大小，或在 Worker 内部使用 R2 分段上传，都不能绕过 Cloudflare 入口的单请求限制。需要大文件 WebDAV 时，应使用能够接收完整文件并主动转换为分片请求的网关。
- WebDAV 与网页共享 50GiB 应用容量限制。回收站、历史发布快照及进行中的上传预留也计入占用；50GiB 不是 Cloudflare 的免费存储额度。

同步软件可能多次查询目录、探测文件和重试上传，因此请求数通常大于文件数。建议降低后台全盘扫描频率，不要以很短的间隔重复扫描大量小文件。

## 协议范围

| 方法             | 用途                                                |
| ---------------- | --------------------------------------------------- |
| `OPTIONS`        | 查询支持的方法                                      |
| `PROPFIND`       | 查询文件/目录属性；支持 `Depth: 0`、`Depth: 1`      |
| `GET`、`HEAD`    | 文件读取及元信息，支持字节 Range                    |
| `PUT`            | 新建或覆盖文件                                      |
| `MKCOL`          | 创建目录                                            |
| `MOVE`、`COPY`   | 移动、复制，支持 `Destination`、`Overwrite` 条件    |
| `DELETE`         | 将文件或目录移入回收站，禁止删除 `/dav/` 根目录     |
| `LOCK`、`UNLOCK` | 独占写锁；支持锁刷新与释放                          |
| `PROPPATCH`      | 属性修改请求；受保护或不支持的属性通过 XML 状态报告 |

覆盖文件会先写入新对象，成功后更换文件引用并增加版本，避免上传中断破坏原文件。客户端应使用 ETag 和 `If-Match` 防止覆盖其他客户端的新版本。

网盘旧数据可能含同目录同名文件。WebDAV 按路径访问，遇到歧义返回 `409`，请先在网页中重命名冲突文件。不会随机选择其中一个。

目录查询每个目录最多 2,000 项，路径最多 32 层。递归删除每次最多处理 1,000 个节点。单次复制最多 12 个节点（包括目录与文件）；超过范围返回 `507`。覆盖目标目录过深时也可能需要分批复制。`COPY` 配合 `Depth: 0` 只复制目录本身。复制使用独立对象与文件记录，不复制公开分享或图床发布关系。

锁会阻止受保护路径及相应目录成员的冲突写入。网页修改同一文件或目录也会返回 `423`；其他目录仍可操作。完成客户端操作并释放锁后可以重试。

## 反向代理

香港反代需要：

- 转发上述 HTTP 方法，不能只允许 `GET`、`POST`。
- 保留 `Authorization`、`Content-Length`、`Content-Type`、`Depth`、`Destination`、`Overwrite`、`If`、`If-Match`、`If-None-Match`、`Lock-Token`、`Timeout` 和 `Range` 等头。
- 保留响应中的 `DAV`、`Allow`、`WWW-Authenticate`、`ETag`、`Lock-Token`、`Timeout` 和 `Content-Range`。
- `/dav/` 禁止缓存，避免向其他请求提供私有内容或过期目录、锁状态。
- 不要将 DAV 请求改写到网页登录页；客户端使用 Basic 凭据认证。

普通反代不会为 WebDAV 自动分片。上传大小和超时还受代理配置、网络及客户端自身限制影响。

## 凭据管理 API

以下接口需要已登录的管理员会话，写请求仍需允许的 `Origin` 和 `X-Drive-Request: 1`。

| 方法     | 路径                     | 说明                                                                 |
| -------- | ------------------------ | -------------------------------------------------------------------- |
| `GET`    | `/api/admin/webdav`      | 返回 `credentials`、`username`、`path`、`maxUploadBytes`             |
| `POST`   | `/api/admin/webdav`      | Body：`{"name":"电脑","expires_in_days":30}`；有效期可为 30、90、365 |
| `DELETE` | `/api/admin/webdav/{id}` | 撤销凭据                                                             |

创建响应为 `{data:{credential,password}}`。后续列表只返回名称、前缀、创建时间、到期时间、最近使用时间和撤销状态，不返回完整密码。

可用下列命令验证目录查询；`curl` 会提示输入独立密码：

```sh
curl --user rcloud -X PROPFIND -H 'Depth: 1' https://233334.xyz/dav/
```

常见状态：`401` 凭据无效、到期或撤销；`403` 操作不允许；`409` 路径/名称冲突或父目录不存在；`412` 条件不满足；`413` 请求过大；`423` 被锁定；`507` 存储或递归操作限制。以响应中的具体说明为准。
