# 界面结构与维护

RCloud 使用蓝灰背景、蓝色操作色和悬浮玻璃面板。导航与操作面板通过半透明背景、细亮边、内高光和柔和阴影呈现层次；背景光为静态 CSS 渐变。文件、图床、文章、分享、设置、登录页和公开阅读页共享字体、控件及明暗主题，不依赖装饰图片或外部字体。

## 页面与响应式布局

- 桌面保留侧栏、搜索栏与内容区域，导航和面板与视口边缘留出间距；文件列表和网格共享选择、排序、分页及操作逻辑。
- 900px 及以下收起侧栏，底部悬浮导航提供文件、图床、文档和更多入口；完整导航通过侧边抽屉打开。
- 600px 及以下的操作对话框使用底部面板。导航、内容底部留白、对话框和编辑器状态栏考虑 `env(safe-area-inset-bottom)`，避免遮挡末行内容与触摸操作。
- 编辑器在桌面显示编辑与预览双栏，在手机上切换单栏；公开文章保留目录、代码高亮及复制入口。
- 页面按内容高度自然滚动；对话框、目录和上传队列仅在内容超出可用空间时内部滚动，空列表不强制占满额外视口。
- 亮色和暗色均通过 CSS 变量定义；键盘焦点可见，Radix 对话框管理焦点，系统减少动画偏好会关闭非必要动画，减少透明度或高对比偏好会启用实色面板。

## 样式与资源

`src/styles.css` 只负责导入，组件布局各自归入对应文件：

| 样式文件       | 内容                                           |
| -------------- | ---------------------------------------------- |
| `tokens.css`   | 颜色、字体、间距、侧栏宽度等公共变量，明暗主题 |
| `base.css`     | 显式基础重置、按钮、焦点、加载及空状态         |
| `shell.css`    | 桌面侧栏、搜索、移动导航、抽屉及页面标题       |
| `files.css`    | 文件工具栏、列表、网格、选择状态及分页         |
| `overlays.css` | 对话框、操作菜单、消息及上传队列               |
| `pages.css`    | 设置、API Token、分享/文章管理及图床           |
| `prose.css`    | Markdown 阅读排版与代码高亮                    |
| `editor.css`   | 编辑器工具栏、双栏与移动端切换                 |

样式使用原生 CSS 和语义类名，不依赖 Tailwind、运行时工具类合并或组件生成器配置。新增视觉状态应放入所属文件，避免新增覆盖整站的补丁样式层。公共页由 Worker 直接返回 HTML，样式保持独立以免加载后台应用；修改主题或标志时应同时检查后台与公共页。

背景模糊只用于导航、工具栏、对话框等独立表面，不放在包住整个应用或编辑器的祖先容器上，避免嵌套模糊增加合成开销或影响固定定位。长列表、编辑区和文章正文使用高不透明度底色，保持文字与选中状态清晰；不对长正文做整块背景模糊，不添加持续动画、跟随指针的滤镜或背景视频。

玻璃色、边框、高光和阴影通过变量定义，明暗主题分别设置。`@supports` 为支持 `backdrop-filter` / `-webkit-backdrop-filter` 的浏览器启用模糊；不支持时使用实色背景。`prefers-reduced-transparency: reduce` 和 `prefers-contrast: more` 关闭透明与模糊，操作层级仍由边框、间距和布局表达。

系统字体无需下载。CodeMirror、Markdown 渲染器及文件预览按页面需要延迟加载；代码语言按需加载，保留现有高亮能力。`docs/screenshots/` 是文档验收图片，不会打包为站点资源。

## 编辑器图片

多选、拖入或粘贴新图片通过 `uploadHostedImage` 复用图床上传流程：获取 `Image-hosting` 目录、分片上传、按内容 MD5 发布并清理重复源，再将 HTTPS 直链插入 Markdown。链接采用当前选择的全球 CDN 或香港反代域名，默认 `s.irin.im`；每批上传使用开始时的选择，已有正文不自动替换。普通文本粘贴保持原有编辑行为。图片上传后即独立公开，不等待文章发布；取消发布、删除文章或移除链接均不会撤销图床图片。

旧文档中的 `attachment:UUID` 继续通过所属文档的受控附件接口预览，发布快照仅开放实际引用的附件，取消发布后旧附件停止公开。新图床图片与旧附件的生命周期分别管理；需要撤销图床图片时从图床操作，可能同时影响引用同一直链的其他文章。

## 公开链接域名

分享/文件直链弹窗、图床列表、文章列表、编辑器发布横幅和发布窗口共用 `PublicLinksProvider`。分段切换控件显示线路名称、域名与选中状态，切换后给出简短反馈，支持键盘与触屏；编辑器工具栏的选择同时用于新图片链接。选择仅保存在当前站点的浏览器存储中，存储不可用时仍可在本次会话切换。

全球 CDN 来自 `adminOrigin`（兼容回退到 `markdownOrigin`），香港反代来自 `filesOrigin`；配置相同时去重，只显示有效选项。仅替换可信来源的公开链接域名，保留原路径、查询参数和片段；不转换任意外部链接、私有下载或上传 API 地址。不同域名的密码分享 Cookie 独立，可能需要重新解锁。

## 图床列表与画廊

每次进入图床默认使用列表，只获取当前页的图片信息。切换画廊后从第一页开始取齐全部记录，再渲染所有图片；图片全部立即加载，不使用懒加载、滚动触发或画廊分页。切换视图或刷新时取消旧请求，避免过期结果覆盖当前视图。记录读取遇到限流时等待后重试当前页，取消操作同时结束等待；读取失败不会把部分结果显示为完整画廊。

列表和画廊复用复制直链、Markdown、下载、撤销、恢复及永久删除操作，保留引用/下载统计。画廊使用管理员私有图片接口，撤销公开直链后的图片仍可查看，浏览画廊不会增加公开引用次数；点击图片打开大图预览。卡片使用自适应网格和固定图片比例，避免图片加载导致布局跳动。

## 验收与变更约束

使用本地测试数据检查桌面、平板和手机，至少覆盖文件列表/网格、空回收站、图床、设置 Token 弹窗、编辑器、登录、分享与公开文章。检查长文件名、空结果、明暗主题、键盘焦点、Esc 关闭、触摸点击、横向溢出以及空页面的多余滚动。

样式变更不应改变认证、文件公开权限、分片上传、50GiB 总容量、MD5 图床命名或 ShareX 接口。业务回归与实际浏览器检查分别执行，详见 [验证指南](verification.md)。发布前运行 `pnpm check`；更新截图时使用本地样例，避免包含私人文件、邮箱、Token 或验证码。
