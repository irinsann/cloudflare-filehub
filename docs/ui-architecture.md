# 界面结构与验收

RCloud 使用同一套页面响应不同屏幕尺寸。桌面侧栏在 900px 以下收起，手机提供文件、图床、文档和更多四个入口；600px 以下的文件操作弹窗使用底部面板。页面支持亮色、暗色及系统减少动画偏好。

## 模块职责

- src/App.tsx：页面编排、编辑器及文件操作状态。
- src/hooks/useFileBrowser.ts：列表请求、取消过期请求、筛选、分页、导航与视图偏好。
- src/components/workspace/：工作空间布局、文件列表、文件操作菜单和上传队列。
- src/lib/upload.ts：网盘与图床共用的分片上传、重试和失败清理。
- src/styles/：颜色与间距变量、基础控件、布局、文件列表、弹窗、管理页面、文章排版和编辑器样式。
- worker/public-styles.ts：服务端输出的公开文章、分享页与登录页基础样式。

## 浏览器验收

本地环境使用测试文件验证，不使用生产账号的私人文件：

- 桌面、平板和手机宽度下无页面横向溢出；长名称保持操作按钮可见。
- 底部导航、抽屉菜单、Esc 关闭及键盘焦点恢复。
- 文件列表和网格切换、排序、选择、搜索及空结果。
- 超过 16MiB 的分片文件、空文件、图床上传与 MD5 直链。
- Markdown 手机编辑／预览切换与桌面分栏、公开文章目录。
- 亮色与暗色模式、可滚动的底部弹窗和安全区域间距。

完整检查仍使用 pnpm check。认证、存储配额、分享权限与回收站行为由现有回归测试覆盖。
