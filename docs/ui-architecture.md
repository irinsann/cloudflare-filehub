# 界面结构与维护

RCloud 使用马卡龙配色：暖纸背景、淡紫主操作色及桃色、薄荷和浅蓝分类色。实色面板、细边框和轻阴影提供层次，采用系统字体，不下载装饰图片或外部字体。明暗主题复用颜色变量。

## 页面与响应式布局

- 桌面采用固定侧栏、搜索栏与内容区域；文件列表和网格共享选择、排序、分页及操作逻辑。
- 900px 及以下收起侧栏，底部导航提供文件、图床、文档和更多入口；完整导航通过侧边抽屉打开。
- 600px 及以下的操作对话框使用底部面板。导航、内容底部留白、对话框和编辑器状态栏考虑 `env(safe-area-inset-bottom)`，避免遮挡末行内容与触摸操作。
- 编辑器在桌面显示编辑与预览双栏，在手机上切换单栏；公开文章保留目录、代码高亮及复制入口。
- 页面按内容高度自然滚动；对话框、目录和上传队列仅在内容超出可用空间时内部滚动，空列表不强制占满额外视口。
- 亮色和暗色均通过 CSS 变量定义；键盘焦点可见，Radix 对话框管理焦点，系统减少动画偏好会关闭非必要动画。

## 样式与资源

`src/styles.css` 只负责导入，组件布局各自归入对应文件：

| 样式文件       | 内容                                           |
| -------------- | ---------------------------------------------- |
| `tokens.css`   | 颜色、字体、间距、侧栏宽度等公共变量，明暗主题 |
| `base.css`     | 显式基础重置、按钮、焦点、加载及空状态         |
| `shell.css`    | 桌面侧栏、搜索、移动导航、抽屉及页面标题       |
| `files.css`    | 文件工具栏、列表、网格、选择状态及分页         |
| `overlays.css` | 对话框、操作菜单、消息及上传队列               |
| `pages.css`    | 设置、API Token、分享/文章管理及图床           |
| `prose.css`    | Markdown 阅读排版与代码高亮                    |
| `editor.css`   | 编辑器工具栏、双栏与移动端切换                 |

样式使用原生 CSS 和语义类名，不依赖 Tailwind、运行时工具类合并或组件生成器配置。新增视觉状态应放入所属文件，避免新增覆盖整站的补丁样式层。公共页由 Worker 直接返回 HTML，样式保持独立以免加载后台应用；修改主题或标志时应同时检查后台与公共页。

界面不使用背景模糊、玻璃滤镜、持续动画或跟随指针的效果。文本区域使用实色底，按钮和状态通过颜色、边框和文字共同区分；主题变量集中维护，不能通过新增全局覆盖层改变各页面行为。

系统字体无需下载。CodeMirror、Markdown 渲染器及文件预览按页面需要延迟加载；代码语言按需加载，保留现有高亮能力。过时界面截图已移除，避免文档展示旧版效果或部署者的数据。

## 编辑器图片

多选、拖入或粘贴新图片通过 `uploadHostedImage` 复用图床上传流程：获取 `Image-hosting` 目录、分片上传、按内容 MD5 发布并清理重复源，再将 HTTPS 直链插入 Markdown。链接采用当前选择的全球 CDN 或香港反代域名，默认来自部署配置 `FILES_ORIGIN`；每批上传使用开始时的选择，已有正文不自动替换。普通文本粘贴保持原有编辑行为。图片上传后即独立公开，不等待文章发布；取消发布、删除文章或移除链接均不会撤销图床图片。

旧文档中的 `attachment:UUID` 继续通过所属文档的受控附件接口预览，发布快照仅开放实际引用的附件，取消发布后旧附件停止公开。新图床图片与旧附件的生命周期分别管理；需要撤销图床图片时从图床操作，可能同时影响引用同一直链的其他文章。

## 公开链接域名

分享/文件直链弹窗、图床列表、文章列表、编辑器发布横幅和发布窗口共用 `PublicLinksProvider`。分段切换控件显示线路名称、域名与选中状态，切换后给出简短反馈，支持键盘与触屏；编辑器工具栏的选择同时用于新图片链接。选择仅保存在当前站点的浏览器存储中，存储不可用时仍可在本次会话切换。

全球 CDN 来自 `adminOrigin`（兼容回退到 `markdownOrigin`），香港反代来自 `filesOrigin`；配置相同时去重，只显示有效选项。仅替换可信来源的公开链接域名，保留原路径、查询参数和片段；不转换任意外部链接、私有下载或上传 API 地址。不同域名的密码分享 Cookie 独立，可能需要重新解锁。

## 图床列表与画廊

每次进入图床默认使用列表，只获取当前页的图片信息。切换画廊后从第一页开始取齐全部记录，再渲染所有图片；图片全部立即加载，不使用懒加载、滚动触发或画廊分页。切换视图或刷新时取消旧请求，避免过期结果覆盖当前视图。记录读取遇到限流时等待后重试当前页，取消操作同时结束等待；读取失败不会把部分结果显示为完整画廊。

列表和画廊复用复制直链、Markdown、下载、撤销、恢复及永久删除操作，保留引用/下载统计。画廊使用管理员私有图片接口，撤销公开直链后的图片仍可查看，浏览画廊不会增加公开引用次数；点击图片打开大图预览。卡片使用自适应网格和固定图片比例，避免图片加载导致布局跳动。

## HTML 上传与文件夹网站

HTML 页面提供拖入或选择多个 HTML/HTM 文件的入口，目标目录默认为根目录 `Html-hosting`。上传队列位于应用层，页面切换不丢失当前状态；复用现有分片上传、容量校验与重试。上传成功后保存 file_id，再调用幂等 hosting 接口发布；发布失败时只重试发布，不重复传输成功文件。

列表显示名称、大小、访问统计、密码/有效期状态与操作。链接使用统一域名选择控件，可以复制、打开、撤销和明确恢复；剪贴板不可用时展示手动复制。撤销与恢复携带服务端版本，冲突后刷新，不用旧状态覆盖新操作。页面不会自动接管普通文件分享，也不会移动既有 HTML 文件。

R2 文件夹菜单继续提供“发布 HTML 网站”，支持密码和有效期。分享管理页可在文件与 HTML 网站之间切换。单文件 HTML 分享和文件夹网站直接显示原 HTML，不添加 iframe 或网盘外壳。资源与浏览器权限边界见 [HTML 网站说明](html-sites.md)。

## 语言

`shared/i18n.ts` 定义中英类型、插值与格式化，`src/lib/i18n.ts` 维护可订阅的当前语言。管理界面和编辑器提供统一语言选择；文件、图床、HTML、分享、设置、WebDAV、上传 Token 及编辑器使用显式的中英文案。API 请求携带当前 Accept-Language。

初始偏好依次读取 localStorage 的 `rcloud-locale`、同名 Cookie 和浏览器语言。选择会立即更新界面及 html lang，不刷新页面或重置上传队列。Cookie 为 zh/en、SameSite=Lax、一年有效，HTTPS 时附加 Secure；它不承担认证。存储不可用时仍可在当前会话切换。不同域名的浏览器偏好分别保存。

登录和公开页面由 Worker 独立渲染，不加载后台 React；其语言壳和错误信息与界面选择保持衔接。语言切换不翻译用户文件名、文章内容或标题，也不修改 API 路径、目录命名、分享权限。

## 验收与变更约束

使用本地测试数据检查桌面、平板和手机，至少覆盖文件列表/网格、空回收站、图床、设置 Token 弹窗、编辑器、登录、分享与公开文章、HTML 上传队列、单文件分享和文件夹网站。检查长文件名、空结果、明暗主题、键盘焦点、Esc 关闭、触摸点击、横向溢出以及空页面的多余滚动。还要检查中英文、长英文操作名、存储不可用时的语言选择，以及发布失败后重试不会重复上传。

样式变更不应改变认证、文件公开权限、分片上传、50GiB 总容量、MD5 图床命名或 ShareX 接口。业务回归与实际浏览器检查分别执行，详见 [验证指南](verification.md)。发布前运行 `pnpm check`；更新截图时使用本地样例，避免包含私人文件、邮箱、Token 或验证码。
