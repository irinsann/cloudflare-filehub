# UI 试用版

本轮采用暖灰白画布、墨绿强调色、窄浮动侧栏与清晰的文件列表。手机使用底部导航和抽屉菜单；图床保留默认列表与一次加载全部图片的画廊。

## 版本

- 初始备份：Git 标签 `backup/ui-20261015-519ec62`，指向 `519ec622fe534d5d5aaeea81833428fc57a840d6`。
- 稳定 UI 加 WebDAV：`d7fa0ab`，线上部署基于此版本。
- 新 UI 试用：分支 `codex/ui-studio-20261015`。界面变更与 WebDAV 功能分开提交，试用版不自动替换线上界面。

本机忽略目录 `.wrangler/backups/ui-20261015/` 保存旧源码 ZIP、生产配置及 WebDAV 迁移前的 D1 导出。生产配置和数据库备份含私人信息，不应提交仓库或放入演示部署。

## 独立演示

```sh
pnpm preview:deploy
```

演示 Worker 名称为 `rcloud-ui-preview`，只绑定编译后的静态资源。它不连接 D1/R2，也没有生产密钥、域名或定时任务。数据由 `preview/fixtures.ts` 提供，图片为本地生成的 SVG；所有写请求在读取请求体前返回 403。

入口：`/drive/`。登录界面演示：`/login`。文件列表、图床、编辑器、分享和设置均使用虚构数据。可切换主题和视图，编辑不会保存。

## 恢复

需要回到旧外观时，部署 `d7fa0ab` 可以保留 WebDAV。初始标签用于恢复加 WebDAV 之前的完整源码。先在独立工作目录构建和核对目标版本，再使用原有生产配置部署；恢复 UI 不需要删除数据库表或回滚用户文件。
